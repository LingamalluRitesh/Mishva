## 🌟 Key Features

1. **Clean Corporate White Aesthetic**:
   - High-contrast typography and crystal-clear input fields.
   - Prominent ultra-HD airport air cargo freighter hero showcase.
   - Dynamic real-time typing animation for key operational slogans.

2. **On-Demand Operations Launchpad ("Click to View")**:
   - Clean, uncluttered homepage—no endless 5,000px vertical scrolling.
   - Dedicated interactive workspaces that mount on-demand:
     - 🔍 **Live Consignment Tracking (AWB)**: Real-time GPS flight telemetry, customs checkpoints & delivery signatures.
     - 💰 **IATA Shipping Rate Calculator**: Volumetric vs scale weight comparison for 220+ countries.
     - 📦 **Free Doorstep Pickup Booking**: Schedule pickup across Ahmedabad & Gandhinagar with export box & electronic scale.
     - 📋 **Customer Self-Service Portal**: Lookup past shipments, download invoices & 1-click re-order.
     - ✈️ **Live Air Cargo Flight Radar**: Active international cargo corridors from Ahmedabad (AMD) & Mumbai (BOM).
     - 📄 **Customs Proforma Invoice Generator**: Generate commercial export packing lists & declarations.
     - 🛡️ **NRI Food & Medicine Guidelines**: US FDA, UK HMRC, vacuum sealing & prescription rules.

3. **Cloud Neon PostgreSQL Integration**:
   - Connected directly to serverless Neon PostgreSQL.
   - Automatic schema migrations and seeding for manifests, pickups, customer accounts, and live CMS content.

4. **Dedicated Standalone Admin Portal (`/admin`)**:
   - Authenticated control deck (`admin@mishva.com` / `mishva@admin2026`).
   - Completely isolated from public site navigation—no double navbars or overlapping floating widgets.
   - Live Website CMS: Edit notice banners, phone numbers, branch addresses, rates, and services in real-time.

5. **24/7 AI Smart Assistant & WhatsApp Quick Action**:
   - 🤖 **Mishva AI Desk**: Positioned at bottom-left, provides 24/7 automated rate quotes, medicine guidance & pickup booking.
   - 💬 **WhatsApp Quick Desk**: Positioned at bottom-right, connects customers directly to live executives at `+91 7623909477`.

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/LingamalluRitesh/Mishva.git
cd Mishva

# 2. Install dependencies
npm install

# 3. Create .env.local file
cp .env.example .env.local

# 4. Start local development server
npm run dev

# 5. Open browser
http://localhost:3000
```
